# Slide deck outline - Autobelay

**The deck itself is [`video/slides.html`](video/slides.html)** - open it in a browser and
export to PDF (see [README-export.md](README-export.md)), or paste into Google Slides,
link-viewable. This file is the outline *of* that deck and should be regenerated from it
rather than edited independently: an earlier version drifted three slides behind the real
thing.

Twenty slides, one idea each. Real screenshots and real output over diagrams wherever
one exists; the three architecture diagrams are generated by
`scripts/render_diagrams.py` and inlined, so editing them means editing that script.

1. **Title** - autonomous options agent on Alpaca's MCP server, account `PA3VS39Y5LE2`, MIT
2. **The thesis in one sentence** - buy defined-risk, short-dated premium when an open model
   sees a reason; code sizes, stops, closes. Why long premium, then the division of labour
   in one line, which the next slide draws
3. **One cycle, every 10 minutes** *(runtime diagram)* - gates, snapshot and code's own exits
   run before the model; its proposals and code's exit sells share one `check_order()`
4. **Greeks: Alpaca's, with Black-Scholes as the backstop** - we believed the free feed had
   none for three days and were wrong; 5,721 of 6,114 contracts carry them, ours fills the
   rest, and `greeks_source` says which
5. **What the model is allowed to see** - one API page is 500 contracts, which on SPY is
   three days; pagination, the coverage journaled per cycle, and the menu that now offers
   strike distance on coarse-strike names
6. **A second opinion from a prediction market** - Kalshi and the chain's own implied odds,
   as a prior; the two gates that withhold one
7. **...and then we grade it** - what a Brier score is, the day's against a 0.25 coin flip,
   and the shadow-graded priors the gate withheld
8. **...and we grade what it says** - the citations audit and the exit-claims audit: every
   figure the model quotes checked against the prior it was shown, every exit reason checked
   against the account; journaled, in the digest, and reporting-only
9. **The agent investigates before it acts** - the research loop: four read-only tools,
   six calls, every one journaled
10. **The leash** - the caps, the exits, the daily loss cutoff, the kill switch, and a
    REJECTED line beside the rule that produced it
11. **Everything is journaled - and four things read it** *(journal diagram)* - the browser
    viewer, Home Assistant, the hourly email, the end-of-day loop
12. **Watching it think, from anywhere** - the Cloudflare-published viewer, and the four
    bugs it caught in two days that no test would have
13. **Home Assistant, over MQTT** - three accounts on one responsive dashboard, the kill
    switch that stops only one of them, the knobs that need no deploy, and what reaches a
    phone versus what deliberately does not
14. **It runs on our own hardware, not a laptop** *(infra diagram)* - CI, the freeze window,
    the self-hosted runner, credentials that never leave the box, and the tunnel
15. **Built to be changed while it is running** - 795 tests with no keys and no network,
    Docker-only dev, `--dry-run`/`--force`, runtime overrides
16. **The daily loop** - digest, one change, override or config PR, deployed before the open
17. **Choosing the model, honestly** - the gates a model has to clear, the one rejection
    that clears all of them mechanically and fails on instruction adherence, and the
    admission that no bake-off picked the incumbent
18. **The experiment farm** - three live paper accounts, one deliberate difference each
19. **Results** - equity Mon-Thu, round trips, exit mix, official vs challengers, and an
    honest sentence about what didn't work
20. **What's next, and thanks**

Slides 3, 11 and 14 carry the diagrams and double as the video's diagram frames.

## Before exporting

Numbers that go stale, and where they appear:

| Number | Slides | Refresh with |
|---|---|---|
| tests | 14, 15 | `python -m unittest discover -s tests 2>&1 \| tail -3` |
| merged PRs, deploys | 16 | `gh pr list --state merged --limit 300 --json number -q length` |
| chain / Greeks counts | 4, 5 | `python scripts/last_cycle.py --account official` |
| Brier scores | 7 | `tail -3 logs/prior_scores.jsonl` on CT 108 |
| catalog counts | 17 | `python scripts/verify_models.py --all-configs --rejected` |
| Results | 19 | after Thursday's close |

Then, in order:

```sh
python scripts/make_spots.py          # if a slide illustration changed
python scripts/make_cover.py --png    # if the cover or its hero crop changed
python scripts/render_diagrams.py     # if any architecture diagram changed
python scripts/fit_slides.py          # a slide that no longer fits loses content silently
python -m unittest discover -s tests  # image refs and diagram hashes
```

and re-export - see [README-export.md](README-export.md).
